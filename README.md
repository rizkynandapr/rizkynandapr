## What I do

Right now I'm an AI Trainer at Aksoro, building customer service chatbots for clients on the Malika (Cekat) platform and wiring them into n8n.

Day to day that means writing and debugging system prompts, connecting AI agents to WhatsApp and clients' internal tools, and fixing whatever breaks once real customers start typing. I came into this from data science, so I still lean on Python and a bit of ML when a problem calls for it — but most of my work now is prompts, pipelines, and API glue.

Things I work with a lot: RAG setups, agent routing, knowledge source tuning, and the unglamorous debugging that decides whether a bot is actually usable.

## Featured projects

### [WhatsApp AI Chatbot for SMBs](https://github.com/rizkynandapr/n8n-whatsapp-ai-chatbot) — Universal n8n template
`n8n` `WhatsApp Cloud API` `Claude API` `Google Sheets`

My cousin makes raincoats, and every rainy season one person tries to answer a flood of WhatsApp orders by hand. Every small business here has some version of that problem, so I built the fix once as a reusable template.

It turns a WhatsApp Business number into an AI agent that answers product questions with memory of the conversation, spots a complete order and drops it into Google Sheets, pings the owner right away, and chases up leads that went quiet. Everything client-specific sits in one config node, so setting it up for the next business takes under 30 minutes. Open-sourced with the setup docs and the reasoning behind the architecture.

### [ApplyIQ](https://github.com/rizkynandapr/applyiq-web) — AI job application assistant
`React 19` `Vite` `n8n` `Supabase` `LLM`

A web app that does the repetitive parts of job hunting for you: match your resume to roles worth applying to, then draft a cover letter for each one. The resume gets parsed in the browser (pdf.js, mammoth) so nothing leaves as raw file, an n8n pipeline scores each listing against your profile, and the results show up on a Supabase dashboard with match meters and one-click copy.

### [TalentScout](https://github.com/rizkynandapr/TalentScout-AI-Recruitment) — AI recruitment pipeline
`Workflow Automation` `Prompt Engineering` `LLM Inference`

Screening CVs by hand doesn't scale, and two reviewers rarely agree on who's qualified anyway. This takes a CV and a job description, runs an LLM gap analysis against the requirements, and scores the fit on fixed weights (40% hard skills, 30% experience, 20% education, 10% achievements) so every candidate gets judged the same way. Output is an HTML dashboard a hiring manager can actually act on.

### [Clickbait Detector](https://github.com/rizkynandapr/clickbait-detector) — NLP headline classifier
`TensorFlow` `LSTM` `Streamlit` `Hugging Face`

An LSTM trained on about 32k balanced English headlines, hitting ~98% accuracy with 0.99 precision on the clickbait class. I put it behind a live Streamlit app so people could paste a headline and get an answer instead of trusting the number blind. → [Live demo](https://huggingface.co/spaces/nandutt/clickbait_detektor)
